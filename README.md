# obsidian-scripts

Some standalone ([snippets/](./snippets)) as well as [templater](https://silentvoid13.github.io/Templater) templates/scripts

## Using templater scripts
Make sure to view the [scripts/templater](scripts/templater) scripts as **Raw** for proper formatting

Save them in **Templater** `Template folder location` (see [templater docs](https://silentvoid13.github.io/Templater/settings.html#general-settings))


## Key plugins
- [Templater](https://silentvoid13.github.io/Templater) **(required)**
- [QuickAdd](https://quickadd.obsidian.guide/) (optional)
- [Codescript Toolkit](https://github.com/mnaoumov/obsidian-codescript-toolkit) (optional)
