# obsidian-scripts

Some standalone scripts as well as miscellaneous scripts

## Using templater scripts
Make sure to view the [./scripts/templater] templates/scripts as **Raw** for proper formatting

Save them in `templater` **Templates** folder location

Mostly used in tandem with:
- [templater](https://silentvoid13.github.io/Templater)
- [QuickAdd](https://quickadd.obsidian.guide/)
- [obsidian-codescript-toolkit](https://github.com/mnaoumov/obsidian-codescript-toolkit)
